# 飞书交付

仅在读取或写回飞书已有复盘文档时读取本文件，沿用用户在当前任务中的授权与最新在线内容

本包不附带飞书账号或连接工具。文字复盘无需飞书环境；写回需要可用的 `lark-cli`、当前用户身份和目标文档权限，配套脚本需要 Python 3.9 或更高版本。没有工具或权限时，继续交付本地复盘或待写回的具体建议，向用户说明尚未同步，不把本地完成说成在线已完成

## 读取与局部写回

- 环境提供 `lark-doc` 时按其指令读取文档；没有该技能但已有可用的 `lark-cli` 时，先用当前 CLI 帮助确认读取命令，取得最新全文、文档标识和 revision。沿用同一任务中已有授权；用户已要求在原文档补充或写回时直接完成相应范围，不新增确认门槛。只读审查不自动写回。
- 写回已有飞书复盘时，默认用紫色区分新增建议；用户指定的颜色、格式和已有明确约定优先。只对本次新增或修订的建议应用该样式，不改变原文样式。
- 写前以当前文档为准定位对应题，保护用户最新修改。遇到结果不确定的写入，先回读对应位置核实，避免重复追加；确实受权限或格式限制时说明具体未完成项。

## 发布前检查

- 写回前阅读 [正文检查与发布](publish-check.md)，用 `scripts/review_gate.py` 检查本轮全部新增或替换正文。先完成逐段内容复核，再通过该脚本发布；不直接调用 `lark-cli docs +update` 或重放旧的业务写入脚本。
- 程序筛查已知提醒句式；作者另外按校准案例检查同义改写、答案实用性、技术含义和用户修改是否保留。语义复核针对当前稿，不得自动勾选通过。检查失败先修改，再检查，不向学员输出检查记录，也不新增用户批准步骤。
- 写入入口校验稿件摘要、语义复核记录和远端 revision；任何一项不匹配即停止。写后逐块回读。此入口提供工作流约束，不代表其他工具已被系统禁用。
