# 飞书交付

仅在读取或写回飞书已有复盘文档时读取本文件，沿用用户在当前任务中的授权与最新在线内容

本包不附带飞书账号或连接工具。文字复盘无需飞书环境；写回需要可用的 `lark-cli`、当前用户身份和目标文档权限，配套脚本需要 Python 3.9 或更高版本。没有工具或权限时，继续交付本地复盘或待写回的具体建议，向用户说明尚未同步，不把本地完成说成在线已完成

## 读取与局部写回

- 环境提供 `lark-doc` 时按其指令读取文档；没有该技能但已有可用的 `lark-cli` 时，先用当前 CLI 帮助确认读取命令，取得最新全文、文档标识和 revision。按最新要求沿用已有授权，不重复确认已授权的写回；仅要求复查、先贴改稿或暂不写回时保持只读，不能沿用旧授权扩大本轮范围。
- 写回已有飞书复盘时，默认用紫色区分新增建议；用户指定的颜色、格式和已有明确约定优先。只对本次新增或修订的建议应用该样式，不改变原文样式。
- 写前以当前文档为准定位对应题，保护用户最新修改。遇到结果不确定的写入，先回读对应位置核实，避免重复追加；确实受权限或格式限制时说明具体未完成项。

## 发布前检查

- 按 [正文检查与发布](publish-check.md) 完成当前稿的程序筛查、逐段内容复核，再经 `scripts/review_gate.py` 发布并核验。该文件集中维护补丁、复核摘要、版本核对和失败处理要求；不直接调用 `lark-cli docs +update`，不重放旧脚本，也不把复核过程变成额外的用户批准步骤。
