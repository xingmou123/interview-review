# 正文检查与发布

本流程用于面试复盘新增/替换的文字建议。原题、原答、录音与用户保留的内容不作为禁词清洗对象。检查记录仅保存在作者工作目录，不写给学员。

仅交付聊天文字或本地 Markdown 时，无需准备飞书补丁或运行发布命令。下面的脚本路径相对于本 Skill 根目录；可在该目录运行，或改用脚本的绝对路径。脚本使用 Python 3.9+ 标准库，`check` 不依赖飞书，`publish` 需要本机已登录的 `lark-cli` 与目标文档读写权限。

## 1. 准备小范围补丁

先通过可用的飞书读取工具取得最新全文与 revision。把本轮全部补丁保存成 UTF-8 JSON；每项只替换一块已有建议，或在原段落后插入建议。不要覆盖全文。

```json
{
  "document": "文档token",
  "revision": 12,
  "operations": [
    {
      "command": "block_replace",
      "block_id": "目标块ID",
      "expected_text": "建议：",
      "content": "<p><span text-color=\"purple\">建议：正常总线预算约 41%，压力测试提高到 70%，观察目标排队与执行时间</span></p>"
    }
  ]
}
```

支持 `block_replace` 和 `block_insert_after`。多段新增内容放在同一项的多个 `<p>` 中。`expected_text` 必须等于刚读到的目标块全文。新增文字默认紫色；用户指定颜色优先，在计划顶层填写 `review_style`，包含 `color`（合法色名）、`readback_color`（从现有源样式核对的 `rgb(r,g,b)`）和 `basis`（用户要求或已有约定）。正文与回读均按选定颜色校验，该设置同样绑定复核摘要。不能将正文隐藏在属性、图片或资源块中。需要图表/资源等其他编辑时用对应技能，仍先复核学员可见文字，不能把本入口用于这类内容的发布。

## 2. 程序筛查与逐段内容复核

```powershell
python -X utf8 scripts/review_gate.py check --plan path/to/patch.json
```

退出码 0 只表示格式、双引号和已知问题句式通过，并输出 `plan_sha256`。退出码 2 表示不通过，报告给出补丁项及问题句。脚本只检查新增或替换的可见文字，代码语法可保留双引号；原题、原答、自评和用户已有文字不作为清洗对象。脚本会拼接富文本，处理全角字符和零宽字符，识别已知同义提醒；它不是完整语义判断器。

作者同时读取原题、原答、项目手稿和用户改稿，通读全部补丁，对照 `review-calibration.md`，逐项检查；不能脱离原答，仅凭建议文字判断“没问题”是否恰当：

- 没有数据/经历口径提醒、制作交代及换词后的同类内容
- 仍有针对本题的具体解释、做法或可直接口述的回答；原本答得好的允许“没问题”
- 技术含义与事实准确，没有通过改成无依据的历史断言来消除提醒
- 原题原答与用户删改得到保留，没有恢复用户删掉的文字

将实际复核结果保存为独立 JSON，绑定刚检查的整份计划摘要：

```json
{
  "plan_sha256": "check输出的完整摘要",
  "reviewer": "实际复核者标识",
  "checks": {
    "no_author_meta": true,
    "answers_useful": true,
    "technical_meaning_preserved": true,
    "user_edits_preserved": true
  },
  "findings": []
}
```

这份记录证明完成了指定稿件的复核步骤，不冒充独立模型评测或自动语义检测。存在问题则先改稿，重新生成摘要并复核；不提供忽略筛查、跳过复核或强制发布选项。

## 3. 发布与回读

```powershell
python -X utf8 scripts/review_gate.py publish --plan path/to/patch.json --review path/to/review.json --audit-dir path/to/audit
```

入口在调用写 API 前复查正文和复核记录，读取当前 revision 并核对目标原文。以只读快照确定补丁内容，逐项写入并立即回读，核验新增文字、颜色、位置及原有未改块的内容/样式/顺序。检测到并发编辑、警告、部分成功或回读差异就停止，不自动重试写入。保留审计文件后重读线上状态，再准备剩余补丁，避免重复插入。

入口内部调用 `lark-cli`，身份为 user；可用 `--lark-cli` 指定安装路径。它不是系统权限隔离，无法禁止拥有任意命令权限的调用者绕过脚本。技能要求此工作流的文字写入都经过本入口，不声称已经全局禁用了 CLI。

## 验证修改

运行 `python -X utf8 scripts/test_review_gate.py`，覆盖真实出错句式、同义表达、应保留的技术解释、双引号规则，以及发布前阻断、稿件变更、用户修改与回读。测试使用本地替身，不访问真实飞书、不上传学员材料。真实运行记录另存自己的工作目录，区分离线筛查、受控发布测试与真实远端写入。
